# تقرير تنفيذ مراجعة المنطق — Focusly 1.1.0

المرجع: مراجعة 2026-10-02. هذا التقرير يصف التغيير الفعلي وأدلة التحقق، ويُبقي المراجعة الأصلية محفوظة. التاريخ: 2026-10-03.

## نطاق العمل

شمل التنفيذ المصادقة وعزل الحساب، النقاط والمهارات، الجروبات والتكليفات والتحديات، المهام والعادات والأهداف، GTD وPARA، التعلم والكروت، الصحة والتغذية والعلاقات، Pomodoro والوقت، التقارير، التذكيرات، والنسخ والإصدارات. أضيفت أدوات الإنتاجية المجانية إلى التطبيق القائم.

التغييرات لا تعتمد على Cloud Functions أو Cloud Storage أو AI مدفوع، ولا على شهادة Windows مدفوعة. المشروع الحقيقي `focusly-87187` بقي بدون فوترة. الخطة المجانية لها حصص استخدام؛ المجانية لا تعني استخدامًا بلا حدود.

## منطق الحفظ الجديد

- هوية إنجاز ثابتة ومشفرة SHA256، وسجل غير قابل لإعادة الكتابة، وتحديث الرصيد في المعاملة نفسها. إعادة فتح عنصر أو استرجاعه لا تصنع مكافأة جديدة لنفس الإنجاز.
- UID يُلتقط قبل الانتظار. العمليات المحفوظة لحساب A لا تُنفذ بهوية B. صندوق الآثار يحتفظ بفشل الحفظ ويعرض إعادة المحاولة.
- التقدم الشخصي وتقدم تكليف الجروب متطابقان في معاملة واحدة. التعريف الموزع ثابت؛ يستطيع العضو تسجيل تقدم وقرار مسموح، دون تغيير القفل أو هوية التكليف.
- سلسلة العادة تعتمد على سجلات الأيام المستهدفة. مجرد قراءة قائمة العادات لا تكتب reset جديدًا.
- الروابط والحذف لهما خطوات محفوظة واستئناف. التراجع يحتفظ بهوية المصدر وسجل المكافأة. الهدف يشتق المرحلة من كل المهام المرتبطة مع تمييز التجاوز اليدوي.
- الأرقام التاريخية مبنية على بيانات مؤرخة. تاريخ غير معروف يظل غير معروف؛ لم تُختلق أيام إنجاز أو تقييمات سنوية قديمة.

## حدود المنصة والتحقق

- Windows يستخدم Electron وتشغيل Flutter Web مع SDK Firebase محلي. تشغيل Flutter Windows الأصلي ليس مسار التوزيع المعتمد لاتصال Firebase.
- التنبيهات المسجلة لدى Windows تظل لدى النظام بعد إغلاق التطبيق. ظهورها فعلًا يتأثر بإعدادات Windows والهدوء. الحالة «مجدول» لا تدعي وصول تنبيه. إذا لم يرجع Windows حالة التصريح، يعرض البرنامج أن الفحص غير متاح بدل الادعاء بنجاحه.
- الويب يحتاج تبويبًا مفتوحًا للتذكيرات المحلية. لم يُضف خادم إرسال أو ضمان لتنبيه الويب بعد إغلاق المتصفح.
- معاملات Firestore تحتاج اتصالًا؛ الفشل لا يتحول إلى رسالة نجاح. SDK يحتفظ بالذاكرة المحلية، وصندوق الآثار يعيد المحاولة عند عودة الاتصال دون منح مكافأة ثانية.
- البحث يقرأ صفحات 100 عنصر عند الطلب. بعض قوائم الأدوات تعرض أول 100 أو 500 عنصر لتقليل القراءة، مع بيان الحد أو تحميل المزيد بحسب الشاشة. الاشتراكات التاريخية المباشرة قد تستهلك قراءات أكثر مع نمو الحساب.
- اختبارات قواعد الجروب استخدمت حسابات تجريبية على المحاكي؛ الإنتاج لم يكن به جروبات قديمة لترحيلها. تسجيل Google الحقيقي على جهاز المستخدم وظهور التنبيه على كل هاتف لم يُختبرا بحساب بشري.
- تقارير الأداء والقياسات أدوات متابعة شخصية، وليست تشخيصًا أو استشارة صحية. مكتبة StreakLogic القديمة تحتفظ ببعض دوال التوافق غير المستعملة في التطبيق؛ الحساب التشغيلي يستعمل HabitHistoryService المؤرخ.
- ترقية Windows تحفظ بيانات نسخته الجديدة المحلية. بيانات الحساب السحابية باقية؛ انتقال النسخة القديمة الأصلية إلى محرك Windows الجديد قد يحتاج تسجيل دخول وضبط بعض تفضيلات الجهاز.

## حفظ البيانات الحقيقية

أُخذت نسخة خاصة محلية قبل الترحيل، ولم تُكتب بياناتها الشخصية في التقرير. جرى حجز هوية إنجاز المهمة القديمة المكتملة بمقدار صفر ووسم legacy، بلا تخمين تاريخها وبلا تغيير الرصيد. التحقق قارن سجلات الرصيد مع النسخة الأصلية وأثبت بقاءها كما هي. النسخ الخاصة والمفاتيح وكلمات السر مستثناة من Git.

أُنشئ حساب اختبار منفصل لرحلة النسخة الفعلية. فحص الإنتاج أكد قبول الإتمام الذري، إجمالي 10 نقاط بعد ثلاث محاولات لنفس الحدث، ورفض تعديل الرصيد مباشرة. حُذف حساب الاختبار من Authentication وكل مستنداته السحابية (7 مستندًا). المقارنة بعد التنظيف أثبتت بقاء مستندات المستخدمين الأصليين كما كانت.

### ما لا تثبته هذه النتائج

الرحلة الإنتاجية استعملت تسجيلًا بالبريد عبر Firebase SDK بحساب QA؛ لم تكن اختبارًا حيًا لنموذج تسجيل الدخول أو لموافقة Google بحساب بشري. اختبارات النماذج من ضمن اختبارات Flutter. لم يُشغّل APK على هاتف فعلي، ولم تُختبر كل شاشة يدويًا على كل نظام.

البيانات التي لا تملك تاريخًا قديمًا لا تُستكمل بالتخمين. بعض القوائم المباشرة قد تزيد قراءاتها مع نمو الحساب. الويب المغلق لا يتلقى تذكيرًا محليًا بهذا التنفيذ. هذه الحدود معلنة في التطبيق والتقرير، وليست خدمة مدفوعة مخفية.

مثبّت Windows بلا شهادة ناشر تجارية وقد يظهر تحذير SmartScreen. Android يستخدم مفتاح إصدار جديد؛ نسخة سابقة موقّعة بمفتاح debug لا تقبل ترقية مباشرة بمفتاح مختلف. احتفظ بنسخة بياناتك قبل الانتقال، ولا تحذف نسخة هاتفك دون التحقق من نسختها الاحتياطية. مفتاح الإصدار ونسخته الخاصة محفوظان محليًا ومستثنيان من Git.
