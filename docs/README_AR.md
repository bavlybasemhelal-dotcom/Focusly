# دليل Focusly بالعربية

[العودة إلى README الرئيسي](../README.md) · [فتح البرنامج](https://focusly-87187.web.app)

الإصدار الحالي **1.1.0+2**. Focusly مساحة عمل تجمع المهام والعادات والتركيز والتعلم والتخطيط الشخصي، بواجهة عربية وإنجليزية. مبني على Flutter وRiverpod وFirebase Authentication وCloud Firestore، ونسخة Windows تستخدم Electron لتشغيل Flutter Web مع Firebase Web SDK.

## الموجود حاليًا

| القسم | المميزات |
|---|---|
| المهام ويومي | مهام فرعية، أولويات ومواعيد وعدّادات، مصفوفة Eisenhower، ثلاث أولويات يومية وميزانية وقت تقديرية، روابط أهداف ومتطلبات بين المهام. |
| التنظيم والتكرار | Inbox وGTD وPARA، مشاريع ومناطق وموارد وأرشيف، تكرار يومي/أسبوعي/شهري/كل فترة/بعد الإنجاز، قوالب بمعاينة، تعديل جماعي وسلة واسترجاع. |
| العادات والتركيز | أيام مخصصة وتقويم وسلاسل من سجلات مؤرخة، جدول وأحداث متكررة، Pomodoro بوقت فعلي، تقسيم الوقت وتدقيق الوقت اليدوي. |
| التعلم | كتب وسجلات قراءة، كورسات ومسارات ومعرفة، كروت SM-2، مهارات وسجل تقدم، وجلسة تعلم مرتبطة بالمصدر والهدف ومهمة اليوم. |

من القائمة افتح **أدوات الإنتاجية**. `Ctrl+D` يفتح يومي، و`Ctrl+K` البحث، و`Ctrl+N` الالتقاط السريع. المرفق المحلي يظل على جهازك ولا يُرفع لخدمة تخزين.

## التعديلات الأخيرة

- عزل الحساب قبل وأثناء العمليات غير المتزامنة، تهيئة ملف المستخدم، موافقة محفوظة على الشروط، ومعنى فعلي لخيار تذكرني.
- حفظ حدث الإنجاز والسجل والرصيد في معاملة، مع هوية ثابتة تمنع تكرار المكافأة، وأسابيع مؤرخة دون تصفير الرصيد المشترك.
- حماية الدعوات والأدوار والموافقة والعضويات بقواعد Firestore؛ تثبيت تعريف التكليف وتنسيق التقدم الشخصي والجماعي.
- معاملات تقرأ الحالة الجديدة عند التعديل، وحذف قابل للاستئناف، وصندوق آثار محفوظ يعرض الفشل وإعادة المحاولة لكل حساب.
- تقارير تعتمد على تاريخ محفوظ؛ التاريخ القديم المجهول لا يُستنتج بالتخمين، وخطوط PDF وواجهة Windows محلية.
- توصيل الإضافات المجانية بالواجهة: يومي والبحث والتكرار والقوالب وروابط المهام والأهداف والنسخ ومساحة التعلم والصحة.
- جدولة تنبيهات Windows لدى النظام، tray وبدء التشغيل اختياريًا، وفحص إصدار وبصمة عبر HTTPS، ومثبّت عربي/إنجليزي.
- مفتاح إصدار Android مستقل، ونشر Hosting والقواعد على `focusly-87187` مع بقاء الفوترة غير مفعلة.

## التشغيل والبناء

تفاصيل المتطلبات والأوامر في [README الرئيسي](../README.md#quick-start). جرى التحقق باستخدام Flutter 3.41.2 وDart 3.11 وNode 24 وJava 17.

بعد `flutter pub get`، افتح مجلد `desktop` وشغّل `npm ci` ثم `npm run bundle-sdk`، وارجع للجذر وشغّل `flutter run -d chrome`.

- بناء الويب: `flutter build web --release --no-web-resources-cdn --no-wasm-dry-run`.
- مثبّت Windows: `.\windows\installer\build-installer.ps1` مع Inno Setup 6. بعض مسارات أدوات Flutter/Python في السكربتات خاصة بجهاز البناء وتحتاج ضبطًا على جهاز آخر.
- Android: `flutter build apk --release` بعد توفير مفتاح الإصدار و`android/key.properties` بشكل خاص. احتفظ بالمفتاح نفسه للتحديثات القادمة.

ملفات التوزيع تُنتج في `dist/` وهي مستثناة من Git: `Focusly-Setup-1.1.0-x64.exe` و`Focusly-1.1.0-android-release.apk`. التثبيت الافتراضي على Windows في `%LOCALAPPDATA%\Programs\Focusly`. المثبّت غير موقّع بشهادة ناشر تجارية وقد يظهر تحذير من Windows. نسخة Android الموقعة بمفتاح debug سابق لا تقبل تحديثًا مباشرًا بمفتاح مختلف.

## الحدود والتكلفة

الإضافات لا تعتمد على AI مدفوع أو Cloud Functions أو Cloud Storage. Firebase Spark له حصص استخدام؛ راجع [تسعير Firebase](https://firebase.google.com/pricing). معاملات Firestore تحتاج اتصالًا، وصندوق الآثار لا يجعل كل العملية متاحة دون إنترنت. الويب يحتاج التبويب مفتوحًا للتذكيرات المحلية، وجدولة Windows لا تضمن أن المستخدم شاهد التنبيه. بعض القوائم المباشرة قد تزيد تكلفة قراءاتها مع نمو الحساب. بيانات الصحة متابعة شخصية وليست تشخيصًا.

مفاتيح التوقيع وكلمات السر والنسخ الخاصة والكاش وملفات البناء مستثناة من المستودع. إعدادات Firebase العامة تخص المشروع الحالي؛ عند عمل fork مستقل جهّز مشروعك وأعد ضبط إعداداته قبل إنشاء حسابات أو نشر القواعد. `git push` يرفع المصادر ولا ينشر Firebase تلقائيًا.
